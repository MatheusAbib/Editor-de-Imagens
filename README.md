## 📋 Sobre o Projeto

Este é um editor de imagens completo e intuitivo, desenvolvido com HTML5 Canvas. Permite carregar imagens, aplicar filtros, ajustar brilho, contraste, saturação, rotacionar, dar zoom e exportar o resultado em diferentes resoluções.

> **🔗 Demo:** [matheusabib.github.io/Editor-de-Imagens](https://matheusabib.github.io/Editor-de-Imagens)

---

## ✨ Funcionalidades

### 🖼️ Edição de Imagem
- **Upload de imagem** com clique ou arrastar e soltar
- **Máscara Squircle** personalizável (do círculo ao quadrado)
- **Zoom** progressivo (0.5x a 3x)
- **Movimentação** da imagem dentro do canvas
- **Rotação** de 90° em 90°

### 🎨 Filtros e Efeitos
| Filtro | Descrição |
|--------|-----------|
| **Original** | Sem alterações |
| **Vintage** | Tom envelhecido e sépia suave |
| **Preto e Branco** | Escala de cinza |
| **Sépia** | Tom marrom vintage |
| **Vivido** | Cores vibrantes e intensas |
| **Frio** | Tons azulados |
| **Quente** | Tons amarelados |
| **Dramático** | Alto contraste |

### ⚙️ Ajustes Avançados
- **Brilho** (0% - 200%)
- **Contraste** (0% - 200%)
- **Saturação** (0% - 200%)
- **Blur** (0px - 20px)
- **Nitidez** (0 - 100)

### 📤 Exportação
- **Redimensionamento** para: 512×512, 256×256, 128×128, 64×64
- **Formato:** PNG com alta qualidade
- **Download** automático do arquivo editado

---

## 🚀 Como Usar

1. **Carregue uma imagem**
   - Clique na área de upload ou arraste uma imagem

2. **Edite sua imagem**
   - Aplique filtros pré-definidos
   - Ajuste brilho, contraste e saturação
   - Rotacione, espelhe ou inverta cores
   - Dê zoom e mova a imagem

3. **Exporte o resultado**
   - Escolha o tamanho desejado
   - Clique em "Baixar Imagem"
